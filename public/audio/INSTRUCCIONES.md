# Pista de audio

Cuando exista autorización para publicar la canción:

1. Copiar el MP3 autorizado en esta carpeta como `musica-boda.mp3`.
2. Copiar `.env.production.example` como `.env.production`.
3. Ejecutar `npm run check`.
4. Confirmar y subir ambos archivos a GitHub.

Sin `.env.production`, la invitación pública oculta el control de música y funciona normalmente.
